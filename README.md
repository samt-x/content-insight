# content-insight – Felles innsikt

Kunnskapsgrunnlag som skal kunne brukes også etter SAMT-BU (Sammenhengende tjenester for barn og unge):
EU-relatert (blant annet data spaces, EDICs, GovStack), FoU-rapporter, aktuelle medieoppslag og begrepsapparat.

- **Sider:** [Felles innsikt](https://docs.samt-bu.no/innsikt/) på docs.samt-bu.no.
  Repoet er en Hugo-modul, og `content/` monteres på `innsikt`. Adressene er de samme som før flyttingen.
- **Tilgang:** alle i SAMT-BU (`samt-bu-alle`) kan skrive her, direkte fra «Endre» på nettstedet.
- **Historikk:** sidene lå i `samt-bu-docs` under `content/innsikt/` til 2026-11-15, og historikken derfra er tatt med.

Navnet følger regelen for repoer som skal leve videre: typen som prefiks (`content-`). Se Konvensjoner i
[oppgavestyringen](https://docs.samt-bu.no/prosjektleveranser/loesninger/samhandlingsplattform/oppgavestyring/konvensjoner/).
Bakgrunn: [solution-samt-bu-docs#82](https://github.com/samt-x/solution-samt-bu-docs/issues/82) (repo per ansvarsområde).
